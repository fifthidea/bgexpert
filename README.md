# 🩸 Blood Gas Expert — دستیار هوشمند تحلیل گازهای خون (ABG/VBG)

<div dir="rtl">

یک اپلیکیشن بالینی تحت‌وب (WebView) برای **تحلیل پیشرفتهٔ گازهای خون شریانی (ABG) و وریدی (VBG)**، ارزیابی اختلالات اسید-باز، آنالیز متابولیک (Anion Gap) و ارائهٔ پیشنهادات هوشمند برای تنظیمات ونتیلاتور و استراتژی محافظت از ریه.

این ابزار برای کادر درمان (پرستاران، پزشکان اورژانس و مراقبت‌های ویژه) طراحی شده و رابط کاربری فارسی و راست‌به‌چپ (RTL) دارد.

> ⚠️ **سلب مسئولیت پزشکی:** این اپلیکیشن صرفاً یک ابزار کمک‌بالینی و محاسباتی است و **به هیچ وجه** جایگزین قضاوت بالینی، تشخیص و دستورات پزشک معالج نیست. تصمیم نهایی دربارهٔ درمان بیمار، منحصراً بر عهدهٔ پزشک متخصص است.

---

## ✨ امکانات

- **تحلیل کامل اسید-باز:** تشخیص اختلال اولیه (اسیدوز/آلکالوز متابولیک و تنفسی) و اختلالات مختلط.
- **تحلیل جبران (Compensation):** با فرمول‌های استاندارد (مثل فرمول وینتر برای اسیدوز متابولیک) و تفکیک حاد/مزمن.
- **آنالیز متابولیک:** محاسبهٔ Anion Gap، اصلاح بر اساس آلبومین (Adjusted AG) و نسبت دلتا (Delta Gap).
- **اکسیژناسیون:** محاسبهٔ گرادیان A-a وابسته به سن و نسبت P/F.
- **دستیار ونتیلاتور:** پیشنهاد تنظیمات (Rate، TV، PEEP، FiO₂، فشار)، ارزیابی ریسک باروتروما، محاسبهٔ PBW و فشار محرکه (Driving Pressure) و استراتژی محافظت از ریه (ARDSNet).
- **پشتیبانی ABG و VBG:** با محدوده‌های نرمال جداگانه.
- **رابط کاربری دوزبانه (فارسی/انگلیسی):** سیستم i18n سبک و کلید-محور (الگوی PediCalc) با `t(key)`، سیستم listener برای رندر مجدد، تغییر خودکار جهت (RTL/LTR) و ذخیرهٔ انتخاب کاربر. دکمهٔ تغییر زبان در نوار بالا (فقط صفحهٔ اول).
- **رابط کاربری واکنش‌گرا (Responsive).**

## 🚀 اجرا

این پروژه یک اپلیکیشن **سمت‌کلاینت (HTML/CSS/JS خالص)** است. برای اجرا در WebView اندروید (APK)، تمام اسکریپت‌ها در یک فایل واحد `dist/app.bundle.js` باندل می‌شوند.

### ⚙️ ساخت باندل (مهم برای APK)

`index.html` به `dist/app.bundle.js` اشاره می‌کند. **هر بار که فایل‌های `js/` را تغییر دادید، باندل را بازبسازید:**

```bash
node build/bundle.mjs
# یا
npm run build
```

این کار همهٔ فایل‌های `js/` را به ترتیب درست در یک اسکریپت کلاسیک واحد الحاق می‌کند که در `file:///android_asset/` (WebView اندروید) بدون مشکل ترتیب/لود اجرا می‌شود.

### اجرای محلی در مرورگر

```bash
python3 -m http.server 8000   # سپس http://localhost:8000
```

> 💡 در محیط مرورگر، پل نیتیو (`AndroidApp`) در دسترس نیست؛ بخش خرید نسخهٔ حرفه‌ای غیرفعال می‌ماند.

### 📦 بیلد APK در اندروید استودیو

۱. فایل‌های زیر را در `app/src/main/assets/` قرار دهید: `index.html`، `style.css`، `dist/app.bundle.js`، و پوشهٔ `images/`.
۲. اگر `js/` را تغییر دادید، حتماً اول `npm run build` را اجرا کنید تا `dist/app.bundle.js` به‌روز شود.
۳. در اندروید استودیو: **Build → Clean Project** سپس **Rebuild Project**.
۴. هنگام تست روی گوشی، اپ قبلی را حذف/نصب مجدد کنید تا کش WebView پاک شود.

## 🗂️ ساختار پروژه

```
ABG/
├── index.html          # ساختار صفحه و فرم‌های ورودی (به dist/app.bundle.js اشاره می‌کند)
├── style.css           # استایل و طراحی UI (RTL)
├── dist/
│   └── app.bundle.js   # فایل باندل‌شده برای APK/WebView (تولیدشده — دستی ویرایش نکنید)
├── build/
│   └── bundle.mjs      # باندلر (js/* را در یک فایل جمع می‌کند)
├── js/                 # کد منبع (source)
│   ├── i18n.js         # سیستم چندزبانه کلید-محور + دکمهٔ تغییر زبان (الگوی PediCalc)
│   ├── constants.js    # ثابت‌های پزشکی متمرکز (محدوده‌های نرمال و آستانه‌ها)
│   ├── vbg_core.js     # منطق مرکزی تفسیر اسید-باز و محدوده‌های نرمال
│   ├── metabolic.js    # محاسبات آنیون گپ، AG اصلاح‌شده و دلتا گپ
│   ├── ventilator.js   # منطق پیشنهاد تنظیمات ونتیلاتور و محافظت از ریه
│   ├── renderer.js     # توابع رندر HTML نتایج
│   ├── abg.js          # کنترل فرم، اعتبارسنجی، رویدادها و ارکستراسیون تحلیل
│   ├── ui.js           # کنترل رابط کاربری (منو، مودال، سلکت سفارشی)
│   └── Pay.js          # مدیریت وضعیت نسخهٔ حرفه‌ای (پرمیوم)
└── tests/              # تست واحد فرمول‌های پزشکی + باندل (اجرا با Node)
```

### معماری

- ثابت‌ها و توابع محاسباتی از طریق `window.*` بین فایل‌ها به اشتراک گذاشته می‌شوند (بارگذاری با تگ‌های `<script>` در انتهای `index.html`).
- لایهٔ **محاسبات پزشکی** (`vbg_core.js`، `metabolic.js`، `ventilator.js`) از لایهٔ **رابط کاربری** جدا نگه داشته شده تا تست‌پذیر و قابل‌نگهداری باشد.
- ترتیب بارگذاری اسکریپت‌ها مهم است: `constants` → لایهٔ محاسبات → `renderer` → `abg` → `ui`.

## 🧪 تست

تست‌های واحد برای فرمول‌های حیاتی پزشکی نوشته شده و با Node اجرا می‌شوند (بدون وابستگی خارجی):

```bash
node tests/medical-logic.test.js
# اگر محیط شما NODE_OPTIONS سفارشی دارد:  NODE_OPTIONS="" node tests/medical-logic.test.js
```

تست‌ها شامل: تفسیر اسید-باز، آنیون گپ و AG اصلاح‌شده، دلتا گپ، وزن ایده‌آل بدن (PBW)، نسبت P/F و فشار محرکه.

## ⚙️ یکپارچگی با اپلیکیشن اندروید

این وب‌اپ برای اجرا داخل یک **WebView اندرویدی** طراحی شده و از طریق شیء `AndroidApp` با لایهٔ نیتیو ارتباط می‌گیرد:

| متد | توضیح |
|-----|-------|
| `AndroidApp.checkPremium()` | استعلام وضعیت نسخهٔ حرفه‌ای (منبع حقیقت) |
| `AndroidApp.purchase()` | شروع فرایند خرید |
| `AndroidApp.hasUsedTrial()` | بررسی استفاده از تست رایگان |
| `AndroidApp.setTrialUsed()` | ثبت استفاده از تست رایگان |

> 🔒 **نکتهٔ امنیتی:** اعتبارسنجی نهاییِ خرید باید همواره سمت نیتیو/سرور انجام شود. کنترل سمت کلاینت قابل دور زدن است و تنها لایهٔ محافظ نیست.
